# Exercícios

**Exercício 1:** Faça um programa que leia até 6 caracteres e grave em um vetor, na ordem inserida. Imprima o vetor da primeira a última posição e também da última a primeira posição.

**Exercício 2:** Faça um programa que leia 5 números inteiros e grave em um vetor. Este vetor deve ser copiado para um novo na sequência inversa. Faça o mesmo copiando para um novo vetor os números pares e para outro os números ímpares. Imprima todos eles ao final.

**Exercício 3:** Faça um programa que leia 1 número inteiro. Usando este número, crie um vetor com essa quantidade de posições. Dentro deste vetor, deve conter os itens da sequência Fibonacci até a posição formada.

**Exercício 4:** Faça um programa que cria um vetor de char com 10 posições. Copie para um novo vetor cada uma das posições adicionando na próxima o valor da tabela ASC daquele caractere.
